# 24x7RepairHub – Service Booking Website

24x7RepairHub is a responsive service booking website designed for businesses offering home appliance installation and repair services. The platform provides a clean and professional interface that allows users to easily explore services and contact the service provider for bookings.

The website was built entirely from scratch using HTML, CSS, and JavaScript, focusing on responsive design, user experience, and maintainable front-end code.

## Technologies Used

Frontend  
HTML  
CSS  
JavaScript

Version Control  
Git and GitHub

## Features

- Fully responsive layout optimized for mobile, tablet, and desktop devices
- Clean and professional user interface design
- Custom UI components built without frameworks
- Smooth interactive elements using JavaScript
- Client-side form validation
- Structured service sections for easy navigation
- Consistent color theme, typography, and layout design

## Design Focus

The project focuses on creating a modern and easy-to-use service website with clear information architecture. The layout ensures that users can quickly understand available services and easily reach out to book installation or repair services.

Special attention was given to spacing, typography, and visual hierarchy to improve usability and readability.
